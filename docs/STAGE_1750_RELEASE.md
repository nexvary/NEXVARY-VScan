# Stage 1750 Release

Stage 1750 completes portfolio-level operational visibility and production release hardening for NEXVARY VScan.

The release adds dedicated Targets, Scan Center and Reports workspaces, a portfolio summary and authenticated portfolio JSON export, and startup enforcement for production-safe credentials, session secret and secure-cookie posture.

The scanner safety model is unchanged: verified ownership, NEXVARY approval, same-host scope, public-address validation and request budgets remain mandatory.
